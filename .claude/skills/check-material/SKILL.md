# Проверка материала

Проходить по порядку, ничего не пропуская. Про каждый пункт отвечать фактом
(«56 вопросов, счётчик показывает 56»), а не «выглядит нормально».

## 1. Сборка

```bash
node build.mjs
```

Если упала — прочитать сообщение, оно называет файл и поле. Исправить и запустить снова.

## 2. Метаданные

- Все обязательные поля заполнены: `type`, `course`, `course-id`, `unit`, `title`,
  `date`, `status`.
- `ws:course-id` совпадает с именем папки курса.
- `ws:date` в формате ГГГГ-ММ-ДД.
- `ws:title` — то, что Виктория увидит в панели преподавателя и что уйдёт в письмо
  с результатом. Не «Test», а «Unit 9 — What's your opinion?».
- `ws:status` — `draft` у нового материала.
- Есть `<meta name="robots" content="noindex, nofollow">`.

## 3. Вес и ассеты

```bash
wc -c <курс>/<slug>/index.html
grep -c 'src="data:' <курс>/<slug>/index.html
```

- `index.html` меньше 25 КБ. Больше — почти всегда значит, что внутри что-то встроено.
- `grep` возвращает 0. Любое `data:` в `src` — картинку или шрифт надо вынести в файл.
- Шрифт Apercu Pro не подключается заново через `@font-face` — он в `angle.css`.
- Все `src` и `href` ведут на существующие файлы: общие через `/assets/…`,
  свои картинки через `img/…`.

## 4. Ответы (для тестов)

Самое важное: неверный ключ ученик не оспорит, он просто получит незаслуженную ошибку.

- У каждого `data-q` есть `data-ans` или `data-ans-list`.
- `data-q` и `data-group` не повторяются.
- У каждого `[data-group]` есть `data-ans`, и это значение совпадает с одним из
  `data-val` внутри — иначе верного варианта в задании физически нет.
- У каждой `section.card` есть `id` и `data-name`.
- **Перечитать все ответы по смыслу.** Особое внимание: варианты написания
  (`lorry|truck`, `color|colour`), формы глагола, артикли. Где возможно больше одного
  ответа — должен быть `data-ans-list`.
- Число вопросов в `progress-label` совпадает с реальным:

```bash
grep -o 'data-q=' index.html | wc -l ; grep -o 'data-group=' index.html | wc -l
```

## 5. В браузере

```bash
python3 -m http.server 8080 -d _site
```

- Пройти материал целиком и получить 100%.
- Пройти ещё раз с нарочно неверными ответами — подсветка ошибок и показ верного варианта.
- «Начать заново» очищает всё.
- Если есть отправка: без имени — понятная ошибка; до нажатия «Проверить ответы» —
  понятная ошибка. Реальную отправку делать только с именем «TEST».
- Ширина экрана 375px: ничего не уезжает вбок, поля и кнопки нажимаются пальцем.
- Шрифты применились — заголовки не системным Arial.
