# Перенос старого материала

У прежних материалов шрифты и картинки вшиты в файл как base64: 800 КБ там,
где содержимого на 30 КБ. Такой файл нельзя ни редактировать, ни быстро открыть
с телефона. Задача — разобрать его на части.

## 1. Осмотреть, не читая целиком

Файл может быть огромным — **не открывать его инструментом чтения целиком**,
контекст кончится. Сначала посмотреть, что внутри:

```bash
wc -c ФАЙЛ.html
grep -o 'data:[a-z/+]*;base64' ФАЙЛ.html | sort | uniq -c
grep -o '<title>[^<]*</title>' ФАЙЛ.html
grep -o 'formspree.io/f/[a-z]*' ФАЙЛ.html | sort -u
```

## 2. Вынуть встроенное

Скриптом, не руками. Для каждого блока `data:...;base64,...`:

- посчитать sha1 содержимого;
- **логотип ANGLE** (9328 Б) — уже лежит в `assets/brand/angle-logo.png`, встроенную
  копию просто заменить на путь `/assets/brand/angle-logo.png`;
- **шрифты** — уже лежат в `assets/fonts/`, весь блок `@font-face` из материала удалить
  и подключить `/assets/angle.css`. Исходные `.otf` в репозиторий не класть никогда;
- **остальные картинки** — сохранить в `img/` рядом с материалом, имена осмысленные
  (`01-tree-roots.png`, а не `img1.png`; брать из атрибута `alt`), в HTML поставить
  относительный путь `img/имя.png`.

Проверить, что не осталось ни одного `data:` в `src`.

## 3. Подключить общее вместо копий

Определить, какого материал вида:

- **тест в стиле Macmillan** (`.info-box`, `header.hero`, `section.card`, кнопка
  «Проверить ответы») → подключить `/assets/test.css`, из `<style>` оставить только
  `:root` с палитрой этого юнита. Скоринговый `<script>` заменить на
  `<script src="/assets/test-engine.js"></script>`, а данные из него перенести в разметку:
  `answerKey` → `data-ans` на `[data-group]`, `sectionNames` → `data-name` на `section.card`,
  название теста и адрес Formspree — в метаданные;
- **воркшит ANGLE** (фиолетовый, логотип, подпись) → подключить `/assets/angle.css`,
  удалить из `<style>` то, что уже там есть: `@font-face`, `:root` с фирменными цветами,
  сброс, `body`, `header`, `.studio-icon`, `.studio-credit`, `.feedback-icon`.
  Остальную вёрстку заданий оставить как есть.

Сверить, что ни один селектор из старого CSS не потерялся: сравнить список селекторов
старого `<style>` со списком в подключаемом файле.

## 4. Проставить метаданные

Блок `ws:*` целиком — взять из `_templates/`. Название и юнит — из содержимого файла.
`ws:status` = `draft`. Если у материала была ссылка на старом Netlify, добавить
`ws:legacy-url` — она покажется в панели преподавателя, чтобы Виктория помнила,
что у задания гуляет и вторая ссылка.

## 5. Проверить, что ничего не сломалось

Это перенос, а не переделка — вид и поведение должны совпасть с оригиналом:

- число вопросов такое же, как было;
- открыть старый и новый файл рядом и сравнить глазами шапку, задания, панель результатов;
- пройти тест целиком, проценты совпадают с прежними;
- отправка уходит на тот же Formspree.

Затем `node build.mjs` и скилл `check-material`.

## 6. Отчитаться

Сказать: было столько-то килобайт, стало столько-то, что вынесено в `assets/`,
что в `img/`, и что осталось на подтверждение (например, неизвестный курс).
