# Новый воркшит

Отличие от теста: воркшит — тренировка, а не оценивание. Ученик проверяет себя сам,
может переделывать, оценка учителю не уходит. Оформление — фирменное ANGLE.

## 1. Собрать вводные

- курс и юнит;
- целевая лексика или грамматика (можно списком слов);
- к чему привязан урок: текст учебника, аудирование, тема для обсуждения;
- воркшит перед уроком (разминка) или после (закрепление).

## 2. Определить место

Путь: `<course-id>/unit<N>-<тема>-worksheet/index.html`,
для разминки — `<course-id>/unit<N>-<тема>-warmup/index.html`.
`course-id` — из `site.config.json`.

## 3. Создать файл

Скопировать `_templates/worksheet.html`.

**Метаданные**: `ws:type` = `worksheet` или `warmup`, `ws:status` = `draft`,
`ws:formspree` пустой. Если Виктория просит собирать ответы — поставить ярлык курса
и добавить блок отправки (см. ниже).

**Бренд ANGLE — обязательная часть, не отступать:**

- подключён `/assets/angle.css`, ничего оттуда не дублировать;
- в шапке логотип `/assets/brand/angle-logo.png` и подпись `by Viktoria Syuzyova`;
- цвета только фирменные: `--purple:#5E4877`, `--black:#2D2926`, `--yellow:#FED500`;
- заголовки разделов — прописными, с жёлтым треугольником (класс `angle-marker`);
- углы прямые: `border-radius:0`, скруглений в этом стиле нет;
- шрифт Apercu Pro подключается сам, `@font-face` не писать.

**Задания.** Вёрстка своя под каждое упражнение, общего движка здесь нет.
Что должно работать всегда:

- нажатие на вариант сразу подсвечивает верно/неверно (`--correct` / `--wrong`);
- есть кнопка «Start over», чтобы пройти заново;
- строка со счётом после проверки — как обратная связь, не как оценка;
- кнопки не ниже 44px, `touch-action:manipulation` — их нажимают пальцем на телефоне;
- если задание на соответствие — сначала выбираем слово, потом определение.

**Отправка результата (только если попросили).** Скопировать из `_templates/test.html`
блок `.results-panel` с `#sendBtn` и `#sendStatus`, подключить `/assets/test-engine.js`
и заполнить `ws:formspree`. Тогда разметку ответов надо привести к конвенции движка
(`data-q` / `data-ans` / `data-group`), иначе он ничего не посчитает.

## 4. Проверить

```bash
node build.mjs
```

- открыть страницу и пройти каждое задание, включая неверные ответы;
- проверить на узком экране (375px) — ничего не уезжает вбок;
- логотип и подпись на месте, шрифт Apercu Pro применился;
- ни одного `src="data:..."`.

Затем прогнать `check-material`.

## 5. Сказать, что делать дальше

Путь, будущий адрес, и: **GitHub Desktop → Commit to main → Push origin**.
Напомнить, что материал `draft`.
