# Передача Claude: кнопки оценок и текущий юнит в карточках трекера

Дата: 27 октября 2026.

## Жалоба

На компьютере не видно отклика кнопок поведения/активности. Родительская карточка показывает Unit 1, хотя в основной странице выбран Unit 8; на скриншоте Unit 8 ещё не отмечен как Unit started, но в нём уже есть выполненные задания.

## Изменения в assets/tracker/tracker.js

- Выбор юнита для карточки отделён от флага active, который управляет подсчётом баллов. Учительская карточка открывает выбранный в трекере юнит, даже если он inactive. Переключение юнитов внутри карточки сохраняется после оценки.
- В отдельной родительской странице стартовый юнит определяется по последнему начатому юниту или юниту с выполненным заданием этого ученика; случайная сохранённая вкладка u1 из teacher localStorage больше не задаёт стартовый юнит родителя. N/A в будущем юните не считается признаком прохождения. Родитель может переключать доступные юниты вручную.
- Оценённая кнопка выделяется, получает aria-pressed; подтверждение выводится внутри карточки, где его видно и в modal на компьютере. Прежний глобальный toast был вне верхнего слоя dialog и мог скрываться за ним. На мобильном оценка обновляется прямо в странице без открытия дополнительного окна.
- Оценки activity/quality и выбранное число lessons сохраняют визуальное состояние; Demo также сохраняет act/mee при перезагрузке.
- Во всех четырёх HTML-трекерах с общим tracker.js версия ссылки увеличена до v=22, чтобы обновить кэш.

## Проверка

Браузерная проверка docs/tests/tracker-cards.cjs (Playwright, headless Edge, все данные вымышленные, все запросы перехвачены): desktop activity/quality и их POST, видимое подтверждение в modal, сохранение выбранного юнита, мобильные кнопки, родительский Unit 8 с inactive-флагом, навигация родителя, отсутствие выбора будущего юнита только по N/A, сохранение demo после reload. Ошибок JavaScript нет. Запуск: NODE_PATH к установленному playwright; node docs/tests/tracker-cards.cjs. Можно указать TRACKER_TEST_BROWSER для Chromium channel.

Реальные оценки и данные Google Sheets при проверке не изменялись. Флаг Unit started у учеников программно не переключался.

Уточнение Виктории: отсутствие отклика относится к основной странице на компьютере. Поэтому блок выбора ученика, сводка колец и рабочие кнопки activity/quality добавлены непосредственно под настольной таблицей. Нажатие обновляет страницу на месте; родительское окно не открывается. Браузерная проверка включает реальное нажатие на видимую кнопку основной страницы при ширине 1280px.

## Незаданные задания: ссылки отключены

По просьбе Виктории в индивидуальных трекерах (ЕГЭ, Empower, Expert, Gateway B2) задания со статусом N/A / серым минусом должны оставаться видимыми, но их названия не должны быть ссылками у ученика. Уточнение Виктории: у учителя ссылки должны оставаться рабочими при любом статусе. В taskCard() assets/tracker/individual.js для STUDENT && N/A не выводится anchor/href; после назначения (пустой круг, status пустая строка) ссылка возвращается автоматически. Назначено и опубликовано здесь трактуются через существующий статус трекера; отдельный backend-статус published не добавлялся. Подтверждённые и предложенные учеником задания остаются кликабельными. Проверка: node docs/tests/tracker-task-links.cjs. В четырёх HTML-точках входа версия individual.js увеличена до v=23.
