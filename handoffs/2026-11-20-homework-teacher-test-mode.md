# Тестовый режим отправки карточки — 20.11.2026

Просьба Виктории: режим, в котором она сама отправляет карточку не от имени ребёнка, чтобы ловить ошибки вроде Movers 19.11.

## Сервер
Apps Script «ANGLE tracker» (аккаунт angle.assign@gmail.com), тот же deployment и URL; **версия 40** (20.11, 12:36), описание «ANGLE homework teacher dry-run test mode (20.11)». До правки живой Код.gs сверен с локальным `Course checklists/Web tracker/Code.gs` по SHA-256: совпадение, кроме одной строки-комментария перед `hwManualReward_` (в живом файле пустая строка). Локальная копия до правки: `Code.gs.before-dryrun-20261120`.
Изменение в `homeworkSuggestion_`: `dryRun:true` допускается только с верным TOKEN; после всех проверок (ученик, назначение, части, задания, полнота частей, фото через `photoValidate_`, квота писем) возвращается `{ok, dryRun, student, assignmentFound, expected, parts, photos}` до любой записи, письма или награды.
Живая проверка: чужой токен → отказ; Варя, часть reading-voice 19.11 → dryRun ok; Боря WB без фото → «Прикрепи хотя бы одно фото»; неизвестное задание → «Unknown homework task».

## Сайт
`assets/homework-submit.js` (build → `?v=review14`): `#test` в адресе + `angleTracker.cfg` в браузере → жёлтая плашка, кнопка «Проверить отправку (тест)», запрос с `dryRun:true` и токеном, результат в статусе; заявка, фото-коммит, конфетти и локальная квитанция не создаются. Без токена кнопка неактивна. Обычный режим без изменений. Проверено Playwright на перехваченном API (тест, без токена, обычный).

Инструкция: docs/homework-submission-rules.md, раздел «Тестовый режим учителя».
