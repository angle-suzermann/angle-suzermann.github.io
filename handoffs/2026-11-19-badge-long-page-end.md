# Уточнение бейджа — 19.11.2026
Новое прямое указание Виктории заменяет безусловное fixed из предыдущего хэндоффа: короткая страница — fixed слева внизу с единым отступом; длинная — прозрачный footer после всего содержимого в реальной области прокрутки, чтобы не перекрывать элементы. Скрипт v8 измеряет высоту без собственного footer, чтобы не переключаться циклически. В all-trackers работает бейдж внутреннего трекера, внешний скрыт. Окна фото исключены из выбора области прокрутки. Проверено 390/1440: short/fixed, long/end, прокрутка не меняет выбранный режим.
