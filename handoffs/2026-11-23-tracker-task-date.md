# Дата отдельного задания — 23.11.2026
У каждой строки индивидуального трекера добавлена кнопка «Дата задания»: открывает редактор именно этой строки и фокусирует дату. Сохранение использует прежний setTask с идентификатором задания.
Групповая кнопка явно подписана «Даты всех N заданий». Изменение нескольких заданий требует подтверждения. Версия individual.js — 56 во всех четырёх трекерах.
Проверка Playwright с подменой API: перенос отдельного задания сохраняет дату соседнего, календарь и групповые операции. Настоящие данные учеников не изменялись.
