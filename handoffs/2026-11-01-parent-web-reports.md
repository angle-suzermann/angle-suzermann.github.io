# Веб-отчёты для родителей: согласованное оформление

По прямому запросу Виктории 01.11.2026 полный текст уже существующих приватных отчётов теперь можно читать в родительской карточке. Это заменяет прежнее решение «только компактная карточка и скачивание PDF» в части отображения текста. Источником остаётся приватный Reports; публичных текстовых файлов и новых получателей не создаётся.

Общий parent-reports.js применяет оформление ко всем восьми групповым и индивидуальным трекерам. Шапка повторяет Courses/ANGLE prototype/branded-file-preview.html: жёлтый оригинальный логотип ANGLE, авторство, фиолетовая полоса, жёлтая плашка заголовка, три информационных поля. Сохраняются существующие живые кольца карточки, без вставки демонстрационных показателей локального макета.

Разделы отчёта распознаются из Markdown-заголовков и известных текстовых заголовков. Итоги и следующие шаги раскрыты; уроки и подробности можно раскрывать отдельно. Текст без заголовков сохраняется обычными абзацами. Разметка источника экранируется, HTML не исполняется. Свежий отчёт показан первым, предыдущие доступны по датам; PDF скачивается для выбранной записи с прежней схемой расшифровки.

Проверки: build.mjs; tracker-parent-reports.cjs (мобильная карточка, настоящий SVG, раскрытие раздела, архив, выбор PDF нужной даты, побайтовое совпадение, разграничение ученика/курса/плана); tracker-ege-parents.cjs (именная ссылка, clipboard, три кольца, сохранение оценок, отсутствие управления у родителей); проверка парсера на экранирование разметки и сохранение текста.

Расчёт колец, оценки, галочки, приватные Reports, оригиналы PDF и Apps Script в этом изменении не переписывались.
