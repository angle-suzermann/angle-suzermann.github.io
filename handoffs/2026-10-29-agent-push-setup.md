# Как агент пушит: облачная копия (29 октября 2026)

Дополняет [сверку от 28 октября](2026-10-28-migration-reconciliation.md). Материалы и код в этой сессии не менялись. Записано, как агент теперь доставляет коммиты на GitHub, и что проверено.

## Метод

- Права проверены через GitHub API (`gh api repos/…`), пуш — через `git push --dry-run` из облачной копии.
- Состояние `origin/main` и GitHub Actions взяты из облачной копии (`git fetch`, `gh run list`) — это проверенные данные GitHub, а не локальная ссылка.
- Локальная копия на компьютере Виктории проверена через `device_bash`: `git log`, `git status`.
- `node build.mjs` не запускался: заметка не меняет материалы, сборку выполняет GitHub Actions после пуша.

## Что изменилось

- **28.10:** пуш из `device_bash` (shell на компьютере Виктории) не проходит: прокси сессии отвечает 403 на любой запрос к github.com, включая `git fetch`. Из-за этого правило «пушит агент» (коммит `6120bd2`) не выполнялось, и Виктория пушила сама.
- **29.10:** Виктория установила приложение Claude для GitHub на этот репозиторий. API показывает `push: true`; пробный пуш из облачной копии прошёл проверку прав.
- Коммит `e8454f7` (сверка 28.10) уже есть в `origin/main`.

## Как теперь пушить (для следующих сессий)

1. Коммитить на компьютере Виктории только свои пути (`git commit -- <пути>`), чужие изменения не трогать.
2. Перенести свои коммиты в облачную копию репозитория: `git bundle` на компьютере → передать файл в облако → `git fetch` из bundle. Либо, если правка небольшая, сделать её прямо в облачной копии.
3. В облаке: `git fetch origin main`, перенести свои коммиты поверх свежего `origin/main` (rebase), `git push origin HEAD:main`.
4. Проверить результат GitHub Actions (`gh run list`) и сообщить его Виктории.
5. На компьютере Виктории локальный коммит после rebase станет «лишним»: Pull в GitHub Desktop это показывает. Прежде чем отправлять следующий коммит с компьютера, договориться, как синхронизировать копию (Pull или reset к `origin/main` только с её согласия).

Чужие коммиты агент пушит только с явного согласия Виктории.
