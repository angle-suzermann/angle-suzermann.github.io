# iOS: шапка и загрузка трекера — 16.11.2026

## Доказательства
Посмотрена запись экрана (кадры 0/4/7/10/13/16 сек) и два скриншота. На записи шапка каталога в standalone попадает в середину экрана при прокрутке; на скриншотах пустой трекер Loading и бейдж до появления данных.

## Исправлено
- В standalone-шапке удалена добавочная translate3d от visualViewport.offsetTop: fixed уже позиционируется браузером; двойная компенсация сдвигала шапку.
- Групповой и индивидуальный трекеры сразу показывают карточку ожидания вместо пустого view. Бейдж скрыт, пока view пустой/загружается; после данных возвращается штатное положение.
- Тайм-аут API охватывает JSON body, а не только получение заголовков. Один запрос с общим пределом 90 секунд, затем явная ошибка/повтор. Прежние два автоматических повтора и неограниченное ожидание тела убраны.
- loading.js v2 ограничивает ожидание, сохраняет read-only preview, сбой кэша не прерывает свежий запрос; после неудачной отрисовки кэша возвращается карточка ожидания.
- fixed-badge.js v5 подключается сборкой.

## Проверено
Node: зависший запрос, успешный ответ, зависшее чтение JSON в обоих клиентах — PASS. Браузер с фикстурами: оба клиента Loading → задания и Loading → ошибка с Try again, без ошибок JS, бейдж скрыт до содержимого — PASS. Standalone с искусственным visualViewport.offsetTop=180 и прокруткой: верх шапки 0, transform none — PASS. Сборка 340 материалов PASS. Реальные данные не использованы как QA-фикстуры, сохранений в ученические данные/награды нет.

## Ограничения и открытое
Read-only диагностический запрос живого API: группы 48.8 секунды, планы 7.4 секунды, оба ok. Сервер Apps Script не менялся; его задержка НЕ устранена. Поэтому не обещать мгновенную первую загрузку: 90 секунд выбраны, чтобы не обрывать реальный ответ групп на 49-й секунде. Дальнейшая оптимизация backend — отдельная работа после чтения актуального живого кода, не выкладывать старый локальный Code.gs вслепую. Физический iPhone не проверен; воспроизведена причина по видео и проверена компоновка в Chromium. Другие пункты прежних хэндоффов не закрываются.
