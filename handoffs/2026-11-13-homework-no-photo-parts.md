# Части карточки ДЗ без фото · 13.11.2026

Решение Виктории 13.11: фото обязательно только для частей с бумажной работой. Тест, голосовые ответы, чтение, видео и игры отправляются без фото. Виктория получает текстовое письмо на angle.assign@gmail.com (тема прежняя: «Academy Stars N — задание — имя»), заявка попадает в «На проверку». Галочки ученика — заявление, а не приёмка; звезда, как и раньше, только после приёмки всех обязательных частей.

## Сайт
- Часть без фото: `data-homework-photo="none"` на `.step[data-homework-part]` и `"photo": false` у части в `assets/homework-cards.json`. Без пометки часть требует фото (прежнее поведение).
- `assets/homework-submit.js?v=9`: если все готовые части без фото — отправка без вложений, блок фото скрыт, подсказка «Для этих частей фото не нужно»; если среди готовых есть бумажная часть — фото обязательно, как раньше. Конфетти сохранено.
- Отмечены: Movers 10 и 12.11 — `unit8-test`; Flyers 10.11 — все пять частей; Flyers 12.11 — `test`. Starters 13.11 без изменений (только бумажные части). Финал Flyers 10.11: просьба прислать голосовые вместо «фото письменных ответов».

## Сервер (Apps Script) — кандидат, выкладка отдельно
Приватная папка `Course checklists/Web tracker/homework-nophoto-2026-11-13/`: `Code.live-before.gs` (= канонический Code.gs 11.11), `Code.candidate.gs`.
- `hwPartNeedsPhoto_`: флаг из определения карточки; для назначений, сохранённых до флага, — из `HW_BUILTIN_CARDS_`.
- `homeworkSuggestion_`: без фото отклоняет бумажные части (раньше сервер это пропускал); для частей без фото шлёт `hwNoticeMail_` без вложений, ошибка письма не теряет сдачу (`noticeError`). Новые колонки `noticeSent`, `noticeError` в Homework_Submissions.
- `hwValidateCard_` принимает только булев `photo`.
Порядок выкладки любой: старый сервер принимает сдачу без фото, но письма не будет; новый сервер требует фото для бумажных частей, а сайт их и так требует.
