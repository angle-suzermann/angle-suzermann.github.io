## Родителям ЕГЭ

Учитель видит «Карточка для родителей» и «Копировать ссылку родителям» для каждого плана ЕГЭ. Карточка показывает только выбранного ученика, общий процент подтверждённых заданий, подтверждённое количество и прогресс по блокам. Ожидающие проверки задания отдельно и не засчитываются. Не выдумываются оценки качества/активности, которых в индивидуальных планах нет.

Родительская ссылка использует существующий ключ плана с `parent=1`. Это отдельное представление только для просмотра: нет задач с кликабельными статусами, добавления/редактирования и отправки очереди ученических изменений. Набор полномочий существующего ключа backend не менялся; отдельный новый серверный тип ключа не создавался. Ученическая ссылка без parent=1 продолжает работать как раньше.

Кнопка «Скачать отчёт PDF» остаётся. Если файла ещё нет — видимое сообщение, что отчёт будет добавлен позже; автоматически созданного заменителя нет. Уже подключённые оригиналы продолжают скачиваться. Новые отчёты будут подключаться отдельно после создания.

## Проверки

Дополнительно по уточнениям Виктории: во всех индивидуальных трекерах у учителя
над блоком есть «Изменить даты блока» и «Удалить блок». Новые даты применяются
ко всем заданиям выбранного блока; содержание, оценки, баллы и другие блоки
сохраняются. Удаление требует подтверждения и использует прежнюю операцию
deleteTask для каждого задания. Новый backend/deployment не нужен.

Все формы дат (добавление заданий, дата группы, дата отдельного задания через
перенос, даты всего блока) используют нативные input[type=date] с календарём.
Несколько дат поддерживаются. Старые строковые даты распознаются для показа
в календаре, но без пользовательского изменения не переписываются. Случаи
неподдерживаемого старого формата сохраняют прежнюю строку до выбора новой даты.
tracker-block-actions проверяет пакетное изменение двух дат, сохранение
статусов/баллов, соседний блок, reload, отмену/подтверждение удаления и отсутствие
учительских действий у ученика. Все данные и запросы в проверках вымышленные.

Ещё одно уточнение: номера заданий теперь видны перед названиями. При добавлении
каждой строки уже существующий mkTask присваивает следующий n в блоке; этот
номер теперь отображается и у учителя, и у ученика. Название задания и ID
не переписываются. Проверка добавляет две строки и подтверждает номера 2/3,
а также их сохранение после reload.

Последнее уточнение по скриншоту: видимая нумерация независима внутри каждой
группы с датой (wgrp), а не сквозная внутри Block 1. В каждой такой группе
выводятся 1, 2, 3… по её текущему порядку. Поле t.n остаётся внутренним ID
и не переписывается. После удаления строки видимая нумерация идёт без пропусков.
Проверка подтверждает два отдельных блока с номерами 1/1 при прежних ID 2/1.

Сборка сайта; catalog-final (убрана техстрока, два published классификатора с нужными названиями, недавние плитки в desktop/mobile); tracker-ege-parents (учительский preview/ссылка, отдельный ребёнок, фактические 50% на тестовых данных, нет редактирования/очереди записей, заглушка отчёта); tracker-parent-reports (исходные PDF, разграничение ребёнка/курса/плана, отсутствие полного текста). Приватная проверка сравнивает все 14 скачиваний с оригиналами побайтово. Живые Google Sheets не менялись.

### iOS: явный календарь и тип задания (28 октября)
- У каждого поля даты появилась кнопка календаря с собственным месячным grid в dialog: не зависит от Safari showPicker. Выбор даты сохраняется через прежний setTask, старые даты без изменений сохраняются как раньше.
- В Edit тип задания выбирается видимыми radio Before the lesson / Classwork / Homework; при сохранении отправляется только выбранный вариант.
- Мобильная проверка tracker-block-actions: выбор следующего месяца/дня, смена типа, сохранение и reload, затем прежние пакетные даты/удаление/нумерация. Проверено в Chromium mobile viewport; физический iPhone недоступен.

### Порядок заданий и компактные Extras (28 октября, после iOS-календаря)
- Индивидуальные трекеры: учитель перетаскивает ручку ⋮⋮ внутри одной группы с датой. Pointer Events + touch-action:none только на ручке; остальная страница прокручивается как раньше. Есть подсветка места вставки, прокрутка у края окна, клавиатура ArrowUp/Down. У учеников/родителей ручек нет.
- Сохранение работает с текущим Apps Script без переустановки: Tasks.n уже является серверным числовым ключом сортировки. Перемещаемая строка получает уникальный промежуточный числовой n через setTask, запрос адресуется СТАРЫМ n. Остальные поля строки и другие задания не переписываются. n теперь может быть дробным/нулевым/отрицательным: не округлять и не parseInt. Это уточняет прежнюю заметку о неизменных n при одной лишь визуальной нумерации. Видимые номера по-прежнему 1..N внутри даты. Новые строки по-прежнему получают max(n)+1.
- Групповые трекеры: Extra worksheets по умолчанию свернуты (название/ссылка, дата, purpose, баллы, примечание, отметки учеников). Edit открывает черновик; Save отправляет изменённые поля updateExtra и сворачивает форму. Новый +Add открывает форму с Save. Печатание сохраняется в черновике между render, обновление оценок не затирает текст. Черновик не переживает reload до Save.
- Проверки: tracker-task-order (реальное mouse-перетаскивание, touch Pointer Events, keyboard, сохранение ранга/перезагрузка, неизменные отметки/поля/даты, отсутствие управления у ученика); tracker-extra-compact (mock live API, add/save/edit/reload, отсутствие дублей, mobile/desktop); прежний tracker-block-actions прошёл. Реальные Sheets не изменялись в тестах.
