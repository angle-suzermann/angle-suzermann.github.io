## Состояние на 15–17 августа (осталось в силе)

### Подпапки-юниты и автоматические вкладки

Материал курса можно (не обязательно) положить на уровень глубже —
`<course-id>/<группа>/<slug>/`, например `as4/unit 9/water-test/index.html`
или `ege-2027/1.Путешествие/essay-38/index.html`. `build.mjs` находит материалы
на любой глубине сам. Название подпапки — это и есть «группа», из неё
строятся вкладки-фильтры на странице курса и третий уровень вкладок в панели
преподавателя (после `family` → уровень).

### Сортировка каталога (по дате / имени / теме)

На страницах курсов и в панели преподавателя — панель сортировки, три кнопки
над списком материалов (🕓 По дате, 🔤 По имени, 📚 По теме), повторный клик
меняет направление. `.sort-toolbar` — своя, не связанная с `.toolbar` (кнопки
фильтров/вкладок), разметка и стили (см. комментарий в `assets/catalog.css`).

### «Разбивка ошибок» (`mistakes`)

Стандарт скоринга: человекочитаемая `mistakes` — по одной строке на каждый
неверный/пустой пункт вида `Раздел — контекст вопроса → answered "...",
correct "..."`, через хелперы `exTitle`/`itemContext`/`describeWrong`.

### Кнопка «скопировать ссылку на курс»

На каждой странице курса — 🔗 Скопировать ссылку на эту страницу, копирует
`https://angle-suzermann.github.io/<course-id>/` в буфер обмена. Логика —
общий скрипт `copyScript`.

### Кнопка «скачать учебник»

Необязательное поле `textbookUrl` у курса в `site.config.json` — если заполнено,
на странице курса появляется жёлтая кнопка 📘 Скачать учебник. Заполнено для:
`as2`, `as3`, `as4`, `as5`, `oxford-phonics/3`. Решение по авторским правам —
за Викторией по каждому курсу отдельно.

### Дизайн панели и страниц курсов

Карточки материалов (`.card`/`.staff-card` в `assets/catalog.css`) — скруглённые
углы (14px), полупрозрачный фон с блюром, округлые бейджи и кнопки. Палитра
(фиолетовый/жёлтый/чёрный) не менялась.

## Стандартный цикл работы (напоминание)

```bash
node build.mjs                          # собрать и проверить на ошибки
python3 -m http.server 8080 -d _site    # посмотреть локально в браузере
```

Публикация — как обычно: **GitHub Desktop → Commit to main → Push origin**.
GitHub Actions пересобирает и публикует сайт автоматически, около минуты.
