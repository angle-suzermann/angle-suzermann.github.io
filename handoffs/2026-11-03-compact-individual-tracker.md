# Compact individual tracker and course-relative weeks — 03.11.2026

The teacher toolbar has one primary Personal feedback button and a Links and reports disclosure containing sharing, student links and parent reports. Block date/delete controls are under Block settings; adding a task to a date is collapsed until requested. Existing handlers and access remain available.

Week 1 is the calendar week containing the earliest valid lesson date in Block 1 of the selected plan. Later dates continue from that anchor across subsequent blocks. This replaces the earlier fixed Week 39 anchor. Existing task dates, stored marks and task numbering are not rewritten. If Block 1 has no dates, the first available block/raw date provides the initial fallback.

Local checks cover the first week, subsequent weeks, continuity across blocks and multiple dates. Versioned individual.js is updated on all four individual tracker pages.
Mobile date editor: date input, calendar button and remove button use contained grid columns; each date occupies its own row under 600px. At 390px viewport all three fields were measured: children fit and no overlaps. This was checked locally without saving any dates.
