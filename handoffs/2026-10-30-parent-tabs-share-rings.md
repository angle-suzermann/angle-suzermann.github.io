# Родительские карточки: вкладки, общий шаринг и три кольца

- MEE: вместо одновременно открытых списков юнитов — кнопки переключения. Виден один юнит; выбранная кнопка выделяется. Домашние работы и тесты переключаются независимо. Старые мини-показатели по юнитам под кольцами убраны; обычная навигация карточки по юнитам сохранена.
- «Поделиться» доступно во всех родительских карточках с действующим ключом, включая карточки без готового PDF. С PDF используется название отчёта; без него — «Карточка для родителей — имя». Ссылка содержит только существующий родительский доступ. Общий catalog-share остаётся прежним.
- Все индивидуальные планы, включая ЕГЭ и другие курсы, получили три кольца в Summary и родительской карточке: сдача по числу подтверждённых заданий (N/A исключено), качество по оценкам преподавателя или подтверждённым Worksheet/MEE результатам, активность по оценкам преподавателя. Без оценок выводится «оценка пока не добавлена», не 0%.
- У преподавателя доступны оценки качества и активности 1–3 с периодом 2/3/4 урока. Запись использует существующий addActivity; course равен ID индивидуального плана. Родителям управление оценками недоступно.
- Приватный Apps Script обновлён точечно: plans_ возвращает ratings только с совпадающими course=plan.id и student=plan.student. Действующее развёртывание обновлено до версии 14 без изменения адреса или прав. Живой API проверен: один собственный план, поле ratings присутствует, key скрыт. Приватный исходник Code.gs хранится в Course checklists/Web tracker, в публичный репозиторий не добавлялся.

Проверки: tracker-mee-units; tracker-ege-parents (сохранение обеих оценок, повторное чтение в родительском режиме, шесть окружностей, отсутствие кнопок оценивания у родителей, именная ссылка без PDF); tracker-parent-reports (реальное переключение вкладок на мобильной карточке, скачивание исходного PDF); изоляция ratings на серверных фикстурах, приоритет оценки преподавателя, исключение неподтверждённых результатов; build.mjs.
