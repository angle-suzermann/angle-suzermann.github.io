# Неожиданные звёзды: причина установлена, журнал сохранён — 15.11.2026

Результат задачи из [поручения Codex](2026-11-15-codex-task-unexpected-stars.md). Это диагностика; код подсчёта, деплой Apps Script, задания и журнал наград не изменялись.

## Вывод

Семь звёзд объясняются датами **другого блока того же старого плана**, а не показанными в карточке июльско-октябрьскими заданиями. Все семь `Homework_Rewards.source` сопоставились с существующими подтверждёнными домашними Tasks этого блока; даты наград совпали с результатом нормализации дат Tasks.

Даты записаны английским месяцем и днём **без года**. В `hwRewardDateOne_` используется `y = hit[3] || new Date().getFullYear()`: при запуске в 2026 году старые ноябрьско-декабрьские строки трактуются как ноябрь–декабрь 2026. Они проходят нижний порог 11.11.2026. Верхнего ограничения по дню начисления нет; существующие fixture-тесты отдельно разрешают заранее принятую работу с будущей датой.

По `awarded` семь записей созданы подряд 11.11.2026, в одном коротком интервале. Это согласуется с массовым первым расчётом, но точный инициировавший запрос по текущим таблицам установить нельзя. Исторический снимок Tasks на момент выдачи не найден; сопоставление выполнено с текущими строками и локальным исходником сервера. Год старых занятий не следует восстанавливать только по названию учебного года без проверки первоисточника.

## Гипотезы

- **Дата принятия вместо даты ДЗ — не подтверждается.** У всех Tasks из семи источников `suggested` и `acceptedAt` пусты. В текущем коде эти поля используются только для точечного исключения 10 ноября; основная дата группы берётся из `Tasks.date`.
- **Объединение дат — не причина этих семи записей.** Источники образуют семь отдельных однодатных групп.
- Пересоздание Tasks/миграция как причина не доказаны. Для объяснения наблюдения достаточно дат без года; доказательств исторических операций нет.
- На экране выбран один блок, а коллекция показывает **весь план**. Поэтому счёт звёзд не обязан объясняться только выбранным блоком.

## Проверки

- Живой авторизованный POST: `{a:"syncHomeworkRewards",preview:true}`.
- Ответ 15.11.2026, 14:27 МСК: `ok:true, preview:true, added:0`; 22 диагностических записи MEE.
- Журнал прочитан до и после через Google Sheets только на чтение. Все семь целевых записей, включая `lesson/awarded/source/ordinal/sticker`, совпали без изменений.
- 10 локальных диагностических проверок прошли: фиксированный год; смена года; явно историческая дата при позднем принятии; исключение 10 ноября; семь независимых групп; отсутствие acceptedAt; июль–октябрь; будущая принятая работа; preview без записи; сопоставление семи источников.
- Fixture-контекст запрещает запись: `hwPut_` бросает исключение. Ноль вызовов записи. Реальные данные использовались только для локального сопоставления, не для выдачи тестовых наград.
- **Ограничение текущего preview:** `added:0` задано устройством ветки preview. Она не вызывает расчёт выдачи для групп и не возвращает список потенциальных наград индивидуального плана. Поэтому этот ответ подтверждает безопасное выполнение запроса, но сам по себе не доказывает отсутствие кандидатов или корректность календарных лет.

## Решение Виктории в этом чате

**«Звезды сохраняем; я даже рада, что старые работы вошли в счет».** Сохраняются семь звёзд и выданный стикер. Учёт старых выполненных работ принят пользователем; исправление с целью исключить эти семь работ не требуется. Новое массовое ретроначисление этим диагностическим поручением не запускается.

## Рекомендация на отдельную задачу

Не подменять смысл старой даты текущим календарным годом. Для начислений нужны подтверждённый год/ISO-дата либо явные метаданные периода; не угадывать год только из названия плана. Если нужно расширить ретроучёт, оформить его отдельным явным правилом, сохраняя прежние записи и защиту от дублей по source/UID. Текущая защита по source уже есть: изменение интерпретации года само по себе не доказывает повторную выдачу.

Полезно расширить **read-only preview** списком групп-кандидатов и причинами (исходная дата, нормализованная дата, откуда год, основание допустимости), а в карточке пояснить, что коллекция относится ко всему плану. В этой задаче эти изменения не реализовывались и не выкладывались.
