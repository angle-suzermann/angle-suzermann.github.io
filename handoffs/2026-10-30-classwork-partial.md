# Частичное выполнение Classwork — 30 октября 2026

В четырёх индивидуальных трекерах (ЕГЭ/Empower/Expert/GW B2) добавлен сохранённый status `In progress`.

- Для kind=classwork цикл кружка: пусто → In progress (◐) → ✓ → N/A → пусто. Остальные kind сохраняют прежний цикл.
- В статусе In progress виден жёлтый полукружок и метка «Начато — продолжить», tooltip/aria-label уточняет «на следующем уроке». Статус виден ученику/родителям. Баллы/процент/количество выполненных не начисляются до ✓.
- Online score-ring не маскирует ◐; результат Worksheet/MEE остаётся в note/tooltip. Если ученик сообщает о завершении, suggested получает обычный приоритет «?», преподаватель подтверждает ✓ как раньше.
- Для записи используется существующий setTask/status. Изменение Apps Script/таблицы не требуется. Порядок, n, даты, ссылки и баллы не переписываются.

- docs/tests/tracker-classwork-partial.cjs: цикл, сохранение/reload, видимость ученику, 0 баллов за частичное/баллы после ✓, приоритет над score-ring, прежнее поведение Homework. tracker-block-actions.cjs также проверяет регрессию. Тесты используют mock API и не меняют реальные данные.
