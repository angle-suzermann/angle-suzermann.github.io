   может удалять свои lock-файлы, поэтому коммит делает Виктория в GitHub Desktop
   (заметка + строка-ссылка в `CLAUDE.md`). Первая версия этой заметки была
   случайно удалена кнопкой Discard в Desktop и пересоздана 06.11.

   игнорирует, удалить вручную.
8. Окончания строк: `CLAUDE.md` и другие файлы периодически оказываются в рабочей
   копии целиком на CRLF без изменений текста (проверка:
   `git diff --ignore-cr-at-eol` пустой). Причина найдена: Git на Windows у
   Виктории настроен конвертировать LF → CRLF при checkout (предупреждение GitHub
   Desktop 06.11: «Git is configured to convert them to 'CRLF' the next time the
   file is checked out»). В репозитории файлы в LF; Desktop это различие не
   показывает как изменение, а git агента в Linux-окружении (без `autocrlf`)
   показывает. `.gitattributes` в репозитории нет. Следующей сессии с рабочим git:
   1) перед любым коммитом проверить `git diff --ignore-cr-at-eol`; если по файлу
      пусто — вернуть его `git checkout -- <файл>`; если не пусто — не трогать,
      там чужая содержательная правка;
   2) завести `.gitattributes` со строкой `* text=auto eol=lf`, затем
      `git add --renormalize .` и посмотреть `git status` — если перенормализация
      задевает много файлов, закоммитить её отдельным коммитом, не смешивая с
      материалами.
