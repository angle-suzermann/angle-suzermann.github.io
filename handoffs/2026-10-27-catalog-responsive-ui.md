# Каталог и адаптивный интерфейс, 27.10.2026

По просьбе Виктории: спокойный фон рабочих экранов, согласованные счётчики, недавно открытые материалы и адаптация под телефоны, планшеты и ноутбуки.

- `assets/catalog.css`: однотонная рабочая поверхность, читаемые подписи, две колонки плиток на телефоне, сенсорные кнопки от 44px, доступное масштабирование и фокус.
- `build.mjs`: счётчик результатов считает выбранную область, а не все карточки (которые включали личные папки). Общий итог явно включает черновики. Добавлена секция истории и подключение общих файлов интерфейса уроков. Сборка работает на Windows через fs.rmSync/fs.cpSync, путь удаления проверяется; Linux-путь сохранён.
- `assets/catalog-recent.js`: до восьми последних открытий из панели; локальная история браузера, без синхронизации и серверных запросов. Устаревшие ссылки не выводятся. Учительские параметры в историю не записываются.
- `assets/worksheet-ui.css/js`: общая оболочка постраничных уроков с `#scrollArea .page` или `#restoreNote`. Атрибут hidden имеет приоритет; восстановление и сохранение подписаны по-русски; остаётся верхний сброс с существующим подтверждением; план строится по реальным страницам; кнопки страниц доступны с клавиатуры. На телефоне панель инструментов снизу и не перекрывает текст слева. Содержимое учебных заданий не переводится.
- В Distance Learning — Reading Classwork исправлена обработка отправки: успех показывается только после HTTP OK и `success:true`; ошибки отправки отделены от локального сохранения.
- `assets/tracker/tracker.css`: спокойный фон, читаемая легенда, увеличенные сенсорные элементы, safe-area и адаптация диалогов. Логика статусов/баллов не менялась. Версия CSS при сборке вычисляется по содержимому.

Проверка: `node build.mjs`; `NODE_PATH=<bundled node_modules> node docs/tests/catalog-worksheet-ui.cjs`. Тест использует локальный `_site`, headless Edge, размеры 390×844, 360×800, 820×1180, 1440×900 и демотрекеры. Проверяются история, восстановление ответов, отмена сброса, пять этапов, отсутствие горизонтального переполнения, ошибка отправки без реальных запросов. Это не испытание на физических устройствах и не запуск Safari/WebKit.

Предложения по трекерам, пока без изменения поведения: отдельные подписи для учителя и ученика в очереди проверки; явное подтверждение/возврат; отмена последнего действия; точные состояния локального сохранения и синхронизации; список задач, требующих внимания; старт с актуального блока ученика.
