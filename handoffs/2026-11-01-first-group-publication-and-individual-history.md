# Первая групповая публикация и индивидуальная история

Указание Виктории: для групп первая публикация отчётов — 01.11.2026. Тридцать записей более ранних дат перенесены из приватного Reports в Reports_Archive_before_20261101 с проверкой копии перед удалением из выдачи. В активной групповой выдаче остались два отчёта от 01.11.2026; остальные новые отчёты ещё не добавлены. Исходные PDF и зашифрованные файлы не удалялись. Индивидуальные записи при архивировании не затрагивались. Клиент дополнительно скрывает старые групповые записи в локальном кэше.

Для двух индивидуальных учениц собраны готовые документы с компьютера: пять личных фидбеков по одному плану, десять личных и два родительских по другому. Учительские версии, архивные дубли, парные редактируемые источники и предварительный документ на будущую дату исключены. Тексты извлечены из исходных PDF; сами PDF не пересобирались, упаковка проверена побайтовой расшифровкой. Манифест и импорт — в приватной Course checklists/Web tracker/individual-history-2026-11-01.

Разделение выдачи: личные документы имеют приватный Reports.id с префиксом feedback|. Родительские сохраняют прежние ID либо имеют parent|. Плановые клиентские запросы передают audience=student/parent; сервер возвращает выбранный тип только внутри соответствующего плана. Без audience сохраняется родительская выдача. Это разделение двух представлений существующего ключа, не выдача новых полномочий и не создание отдельных паролей для родителя/ученика.

Учительская Summary показывает личный фидбек, «Карточка для родителей» — родительские отчёты. Записи нескольких документов одного дня имеют разные ID; при импорте совпадение plan+source обновляет существующий документ с резервной копией прежней строки. Даты берутся из датированной папки, либо явно помеченных метаданных PDF; неустановленная дата остаётся пустой и показывается как «Без даты».

Проверки: build.mjs; tracker-parent-reports (первая групповая дата, сохранённая индивидуальная история, выбранный PDF); tracker-ege-parents (личный и родительский режимы не смешиваются, правильные ссылки, кольца и отсутствие родительского редактирования); серверная проверка фильтра plan/audience и неверного ключа. Зашифрованные оригиналы публикуются без именного индекса и текстов.
