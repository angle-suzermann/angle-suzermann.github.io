Rule 1. No be — no continuous!

Present Continuous = am / is / are + verb-ing

I'm revising · she's singing · they're cooking

They cooking. → They're cooking.   Matt skiing this week. → Matt is skiing this week.

Exercise 1. Add the missing be

Rule 2. Spelling

-ing: make → making (drop -e) · swim → swimming, get → getting (short vowel + consonant: double) · lie → lying, die → dying (-ie → -y) · ski → skiing, study → studying (just add -ing)

he / she / it: watch → watches, go → goes (-ch, -sh, -s, -x, -o + es) · study → studies (consonant + y → ies) · play → plays (vowel + y → s) · have → has

Rule 3. Questions: the helper verb goes first

Continuous: (Why) + am / is / are + subject + -ing? → Why is Matt studying?

Simple: (Where) + do / does + subject + verb? → Does your mum finish late?

Why Matt is studying?   Do your mum finish late?

Rule 4. State verbs don't like -ing

love, like, hate, want, need, know, understand, believe, belong, have (= own) — usually Present Simple, even “now”.

My dad's loving the guitar. → My dad loves the guitar. · We are having two bikes. → We have two bikes.

But have = eat / do → continuous is OK: We're having lunch. We're having fun!

How to do “Find and correct”

1. Read the sentence and find the verb. 2. Ask: habit or now? state verb? question? 3. Write only the correct verb form.

Example: Jack writes an essay at the moment. → is writing

One sentence is correct — then write OK. Every other sentence has a mistake!
