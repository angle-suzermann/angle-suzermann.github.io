Как пользоваться платформой MEE

Инструкция для ученика · Macmillan Education Everywhere

Добро пожаловать

Эта инструкция проведёт вас через всю платформу MEE — от регистрации и скачивания приложения до выполнения заданий, домашних работ и проверочных. Внутри — реальные скриншоты платформы и три видео от Macmillan Education.

Листайте страницы кнопкой «Дальше» внизу или точками разделов вверху — возвращайтесь к любому шагу в любой момент.

Системные требования

Платформа Macmillan Education Everywhere (MEE) доступна для скачивания на компьютер, планшет и мобильные устройства. Есть и версия в браузере — она открывается по адресу mee.macmillaneducation.com.

Регистрация по email

Новый аккаунт ученика можно зарегистрировать на портале MEE (macmillaneducationeverywhere.com).

  1. 1На главной странице нажмите Register.
  2. 2Выберите Register a new account.
  3. 3Выберите тип аккаунта student и страну проживания, нажмите Next.
  4. 4Заполните имя, фамилию и email, придумайте логин и пароль, примите условия — Submit.
  1. 5Нажмите Go to Macmillan Education Everywhere, чтобы открыть книжную полку (Bookshelf).
  2. 6Нажмите Activate code, введите код доступа, снова Activate code — материалы появятся в библиотеке.
  3. 7Нажмите на плитку курса, чтобы открыть его цифровые компоненты.
Совет. Если у вас активировано несколько уровней одного курса, переключайтесь между ними вкладками уровня прямо на странице курса.

Другие способы входа

Через Google

  1. 1На главной странице нажмите Register, затем Register using Google.
  2. 2Введите почту и пароль Google, нажмите Next.
  3. 3Выберите Student и регион — готово, коды доступа можно активировать сразу.

Через Microsoft

  1. 1Нажмите Register → Register using Microsoft.
  2. 2Введите email и пароль Microsoft, подтвердите разрешения (Accept).
  3. 3Выберите роль student и регион, нажмите Next.

Отвязать аккаунт Google

Settings → Personal details → вкладка Link account → Unlink account → подтвердите кнопкой Unlink.

На планшет и смартфон

  1. 1Откройте mee.macmillaneducation.com в браузере телефона.
  2. 2Нажмите на три точки в правом верхнем углу → Download app.
  3. 3Выберите Android или Apple iOS — откроется Google Play / App Store.
  1. 4При первом запуске войдите в аккаунт или нажмите Register.
  2. 5Отметьте Keep me logged in, чтобы не вводить пароль каждый раз на своём устройстве.
  3. 6Разрешите уведомления (Yes → Allow) — так вы не пропустите новые задания.

На компьютер

  1. 1На сайте MEE нажмите Download app, затем Download напротив вашей ОС (Windows / macOS / Linux).
  2. 2Откройте скачанный файл и нажмите Install.
  3. 3Дождитесь окончания установки и нажмите Finish.
  4. 4Приложение откроется автоматически — войдите по логину и паролю.
Совет. Скачав приложение, можно загрузить содержимое книг для работы офлайн. Заходите в аккаунт онлайн хотя бы раз в две недели, чтобы данные синхронизировались.

Присоединение к учебному заведению

При первом входе платформа предложит присоединиться к своей школе.

  1. 1Если у вас есть код — нажмите на стрелку во всплывающем окне Welcome!
  2. 2Введите код в поле и нажмите Check.
  3. 3Нажмите +Join, чтобы подтвердить присоединение.
Совет. Пропустили этот шаг при регистрации? Вернуться к нему можно в любой момент: Settings → Joining code / class code.

Присоединение к классу

  1. 1Откройте Settings в меню слева → Joining code/class code.
  2. 2Введите код класса, который дал учитель, и нажмите Check.
  3. 3Готово — теперь учитель видит ваш профиль, может назначать задания и проверять их.
Совет. Не знаете код учебного заведения или класса — спросите у своего учителя.

Электронный учебник: показ и навигация

Внутри цифровой книги доступен набор инструментов для чтения и презентации материала на экране.

Полноэкранный режим

  1. 1Full screen mode — открыть страницу во весь экран.
  2. 2Exit full screen mode — вернуться к обычному виду.

Масштаб

Двигайте ползунок зума, чтобы приблизить нужный участок страницы, затем перемещайтесь по ней значком руки. Back to 100% — вернуться к обычному масштабу.

Фокус (Focus)

Переносит по очереди к каждой активной зоне страницы — удобно во время объяснения материала. Внутри доступны стрелки вперёд/назад, аннотации и рука для перемещения.

Быстрые ссылки (Quick links)

Переход к другим материалам курса, связанным с этой страницей — например, к заданию в рабочей тетради.

Поиск

Ищите по номеру страницы или по ключевому слову — результаты появятся в панели слева.

Инструменты аннотирования

Hand / Selection

Hand — перемещение по странице. Selection — выбрать уже сделанную аннотацию, чтобы передвинуть её или удалить.

Pen / Highlighter / Type

Пишите от руки (Pen), выделяйте текст маркером (Highlighter) или добавляйте печатный текст (Type) — для каждого можно выбрать цвет.

Сохранение и удаление

После изменений система спросит, сохранить ли их (Save). Чтобы убрать аннотацию — выделите её и нажмите Delete.

Навигация по страницам

Листайте книгу стрелками или впишите номер страницы в поле вверху и нажмите Enter.

Меню книги

Table of contents

  1. 1Значок Menu → Table of contents.
  2. 2Выберите юнит и урок.

My Bookmarks

  1. 1Add a bookmark.
  2. 2Впишите номер страницы и нажмите Save.

My notes

Выделите текст на странице, нажмите Add a note и впишите заметку. Все заметки можно выгрузить отдельным PDF-файлом (Export to PDF).

All activities

Прямой переход к любому заданию: выберите юнит, урок и название задания в меню.

On-the-Go Practice / Preparation & Practice

Часть курсов включает раздел для самостоятельной практики.

  1. 1Войдите в аккаунт и откройте нужный курс.
  2. 2В My Library выберите Preparation & Practice или On-the-Go Practice.
  3. 3Впервые? Нажмите Launch first activity. Уже занимались? Продолжите с того же места или выберите урок в Table of contents.
  1. 4Нажмите Start, затем Check, чтобы отправить ответы.
  2. 5Платформа проверяет ответы сразу; неверный ответ можно раскрыть кнопкой Show answers.
  3. 6В конце — процент правильных ответов. Try again для новой попытки или Next — дальше.

Challenge

Дополнительная тренировка лексики и грамматики в игровом формате — с таймером и тремя «жизнями».

  1. 1В курсе выберите плитку Challenge.
  2. 2Нажмите Launch first activity или выберите задание в оглавлении.
  3. 3Start — и вперёд: старайтесь не потерять все три жизни до конца времени.
Совет. В оглавлении (Table of contents) юниты, которые вы уже прошли, отмечены зелёной галочкой — удобно отслеживать, что осталось.

Уведомления

Когда учитель назначает, отменяет или меняет домашнее задание — приходит уведомление. Проверьте, что в приложении на телефоне включены push-уведомления, чтобы ничего не пропустить.

Как выполнить домашнее задание

  1. 1School work → Homework.
  2. 2Актуальные задания — на вкладке To do.
  3. 3Нажмите Start, при необходимости откройте View details, чтобы прочитать сообщение учителя.
  4. 4Ответив на все вопросы, нажмите Submit.

Past — задания, срок которых истёк и учитель больше не принимает ответы. Late — тоже неактивные, но ответ всё ещё можно отправить.

Совет. Каждое домашнее задание можно выполнить только один раз — используйте попытку внимательно.

Как выполнить проверочную работу (Assessment)

  1. 1School work → Assessment → вкладка To do.
  2. 2Нажмите Start, прочитайте условия и нажмите Start now.
  3. 3Отвечайте на вопросы и переходите дальше кнопкой Next — таймер виден в левом верхнем углу.
  4. 4По окончании нажмите Submit.

Future — работы, назначенные на будущую дату. Past — уже не активные.

Совет. Проверочную работу нужно выполнить за один раз, без перерыва: если выйти из неё, таймер продолжит отсчёт.

Прогресс

  1. 1School work → Progress.
  2. 2Общий обзор успеваемости — по классной работе, домашним и проверочным работам для каждого курса.
  3. 3View details у нужного курса → отдельные вкладки Coursework / Homework / Assessments со средним баллом.
  4. 4Заходите глубже: юнит → урок → задание, чтобы увидеть балл за каждое отдельное упражнение.

Оценки и обратная связь от учителя

  1. 1School work → Progress → нужный курс → View details.
  2. 2Выберите компонент, домашнее задание или проверочную работу с комментарием учителя.
  3. 3Комментарий — в разделе Feedback.

Календарь

Учитель может добавлять события и приглашать на них учеников — они появятся в вашем календаре.

  1. 1School work → Calendar.
  2. 2Событие от учителя отображается прямо в календаре.
  3. 3Нажмите на название, чтобы увидеть дату, время, место и участников.
