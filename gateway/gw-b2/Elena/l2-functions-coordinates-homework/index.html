Operation · judge the range

C. Odd one out

All options but one go with the phrase. Find the one that does not.

1. Which verb does NOT go with “___ the graph of y = x²”?

Sketch / draw / plot a graph. Build a graph is a calque of “построить”.

2. Which does NOT go with “the line ___ the point (1, 2)”?

passes through or goes through; not via.

3. Which does NOT fit “the ___ of the vector a”?

magnitude or length. Module is a calque.

4. Which does NOT fit “the line is ___ to y = 2x”?

parallel to, perpendicular to. Equal with is not used for lines.

5. Which does NOT fit “the circle ___ (2, −1)”?

with centre (2, −1) or centred at (2, −1).

6. Which does NOT fit “the ___ product of a and b”?

the scalar (dot) product.

2. What does the question want?

1. The gradient of a horizontal line is…

A horizontal line does not go up at all: gradient 0. A vertical line (x = 3) has no gradient.

2. The line x = 3 is…

All points have x = 3: a vertical line.

3. Two lines are parallel when…

Parallel = same gradient. Perpendicular = gradients multiply to −1.

4. If a · b = 0 (and a, b are not zero), then a and b are…

a · b = |a||b| cos θ = 0 means cos θ = 0, so θ = 90°.

5. The centre of (x + 1)² + (y − 4)² = 9 is…

(x − a)² + (y − b)² = r² has centre (a, b). Here x + 1 = x − (−1), so a = −1.

6. “Plot the points” means…

Plot = mark accurately. Sketch = show the shape without exact points.
