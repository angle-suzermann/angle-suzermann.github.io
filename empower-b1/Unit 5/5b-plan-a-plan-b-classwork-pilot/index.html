📌 Open the rules and check your ideas
Zero conditional
If the lizard gets scared, it hides.		if / when + present, present. Something that is always or usually true: facts, rules, habits. Often with usually, always, can.
First conditional
If the scientists succeed, many people will live longer.		if + present, will / won't / can / be able to + verb. One possible situation in the future and its result. We are not sure it will happen.
Advice
If you're tired, go to bed.		if + present, imperative. Advice or instructions, now or in the future.
unless
We play every Saturday unless it rains.		unless = if … not. It is already negative: unless it rains (NOT unless it doesn't rain).
if or when?if = maybe it will happen. when = we are sure it will happen: When we arrive, I'll call you.
Watch outNo will after if / when / unless: If it rains, NOT If it will rain.
Don't forget be: If it's late… / If we're tired…
Comma when the if-part comes first: If it rains, we'll stay in. / We'll stay in if it rains.

Examples in italics in the first four rows: Empower B1+ Student's Book, Grammar Focus 5B, p. 152.

B. Possible or not natural?

Your home study, from memory. Decide, then read the reason.

1. If it will rain on Sunday, we'll train indoors.

After if we use the present, even for the future: If it rains on Sunday…

2. When I'll get to Kazan, I'll text you.

No will after when either: When I get to Kazan…

3. We'll take a taxi unless Grandpa doesn't drive us.

unless is already negative: unless Grandpa drives us.

4. If you feel nervous before your programme, take a deep breath.

Advice: if + present, imperative.

5. If the competition finish late, we'll take a taxi.

the competition = it, so finishes.

6. If the winter holidays begin, I'll go to a training camp.

The holidays will definitely begin, so we say When the winter holidays begin…

7. If we late for training, the coach gets angry.

The verb be is missing: If we're late… (your priority from the last feedback!)

8. If I skate clean, I'll be really happy.

One possible future situation: if + present, will.

Operation · choose

A. Which reply sounds natural?

Both replies are correct English. Which one keeps the conversation friendly and going? Choose, then read why.

1. Your coach: The bus to the rink is cancelled tomorrow.

A bare OK. can sound as if you don't care. A reaction + a plan-B question keeps the conversation going.

2. Mum: Is Grandpa driving us to the station?

A short answer + plan B gives the other person something to answer. One word often sounds dry.

3. You want to ask your coach to skip the morning practice.

I will… sounds like a decision you have already made. Is it OK if I + present…? is a polite request.

4. Your sister: If you fall, the judges will take points off. She is right, but you want to add something.

Fair enough shows you accept her point. Then But… adds your view, and you stay friends.

5. At the hotel reception:

If possible, could we…? is polite. A bare imperative sounds like an order.
