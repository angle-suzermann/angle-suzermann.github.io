Operation · judge

A. Possible or not natural?

Close your book. Read each sentence and decide. The reason appears after you answer. Don't worry about mistakes here: they show us what to practise today.

1. If it will rain on Sunday, we'll train indoors.

After if we use the present, even for the future: If it rains on Sunday, we'll train indoors.

2. If you heat ice, it melts.

Always true, a fact: present + present (zero conditional).

3. When I'll get to Kazan, I'll text you.

No will after when either: When I get to Kazan, I'll text you.

4. We'll go to the rink by car unless the battery doesn't work again.

unless already means if … not: unless the battery dies again or if the battery doesn't work again.

5. If you feel nervous before your programme, take a deep breath.

Advice: if + present, imperative.

6. If the competition finish late, we'll take a taxi.

the competition = it, so finishes: If the competition finishes late…

7. If I'm tired after training, I usually go to bed early.

A habit: present + present, often with usually / always.

8. If the winter holidays begin, I'll go to a training camp.

The holidays will definitely begin, so we say When the winter holidays begin…

9. If we late for training, the coach gets angry.

The verb be is missing: If we're late…

10. If my sister has a competition, our mum always goes with her.

A habit in your family: present + present.

📌 Open the rules and check your ideas
Zero conditional
If the lizard gets scared, it hides.		if / when + present, present. Something that is always or usually true: facts, rules, habits. Often with usually, always, can.
First conditional
If the scientists succeed, many people will live longer.		if + present, will / won't / can / be able to + verb. One possible situation in the future and its result. We are not sure it will happen.
Advice
If you're tired, go to bed.		if + present, imperative. Advice or instructions, now or in the future.
unless
We play every Saturday unless it rains.		unless = if … not. It is already negative: unless it rains (NOT unless it doesn't rain).
if or when?if = maybe it will happen. when = we are sure it will happen: When we arrive, I'll call you.
Watch outNo will after if / when / unless: If it rains, NOT If it will rain.
Don't forget be: If it's late… / If we're tired…
Comma when the if-part comes first: If it rains, we'll stay in. / We'll stay in if it rains.
