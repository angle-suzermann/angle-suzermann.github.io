# ANGLE — handoff по сайту материалов

Обновлено: 2026-08-15. Актуальное состояние репозитория `angle-suzermann.github.io`,
собрано по итогам сессии, в которой восстанавливали и реструктурировали материалы,
добавляли навигацию по подпапкам и правили дизайн панели преподавателя.

Базовые правила репозитория (структура папок, `ws:*` метаданные, шаблоны,
что нельзя коммитить) — в `CLAUDE.md` в корне репозитория. Этот файл — про то,
что изменилось и как сейчас устроен сайт поверх той базы.

## Если подключаете новый аккаунт Claude к этому проекту

Ничего вручную прикреплять не нужно — подключите в Cowork ту же папку
(`D:\...\angle-site\angle-site` — и `Courses\` рядом, если продолжите оттуда
импортировать). `CLAUDE.md` подхватывается автоматически в любой сессии с этой
папкой, это системный механизм, а не файл для загрузки. Этот handoff — обычный
файл, сам не подгружается, поэтому в первом сообщении новому аккаунту стоит
явно попросить прочитать `CLAUDE.md` и `docs/handoff-angle-site.md` — тогда
контекст (правила репозитория + текущее состояние сайта) будет полным.
Память самого разговора (конкретные решения по спорным черновикам и т.п.)
не переносится, но всё важное из неё уже выписано в эти два файла.

## Новое: подпапки-юниты и автоматические вкладки

Раньше материал курса лежал прямо в `<course-id>/<slug>/`. Теперь можно (не обязательно)
положить его на уровень глубже — `<course-id>/<группа>/<slug>/`, например:

```
as4/unit 9/water-test/index.html
expert-advanced/module 3/modals-case-file/index.html
ege-2027/1.Путешествие/essay-38/index.html
```

`build.mjs` находит материалы на любой глубине сам (правка добавлена в этой сессии —
раньше сканировал только один уровень). Название подпапки — это и есть «группа»:
`unit 9`, `module 3`, `1.Путешествие`, `Демо` и т.п. Никакой дополнительной настройки
в `site.config.json` не нужно — группы вычисляются из структуры папок при сборке.

Эффект на сайте:

- **На странице курса** (`/as4/`, `/ege-2027/` и т.д.) над списком материалов
  появляется ряд кнопок-вкладок по группам — клик фильтрует карточки на странице.
  Если у курса нет подпапок (например Oxford Phonics или Placement tests) — вкладок нет,
  ничего не меняется.
- **В панели преподавателя** — то же самое, но третьим уровнем: клик по курсу
  (напрямую или через подвкладку уровня внутри семьи) разворачивает под ним ещё один
  ряд вкладок по группам этого курса. Реализовано как расширение уже существующего
  механизма подвкладок семей (`family` → уровень → теперь ещё и группа).

Чтобы добавить новый материал с группировкой — просто создайте на один уровень
папок больше, чем раньше. Название подпапки станет и названием вкладки, и то же
название попадёт в ссылку на GitHub («исходник» в панели преподавателя).

## Новое: кнопка «скопировать ссылку на курс»

На каждой странице курса теперь есть кнопка **🔗 Скопировать ссылку на эту страницу** —
копирует прямой адрес курса (`https://angle-suzermann.github.io/<course-id>/`) в буфер
обмена. Это открытые страницы (показывают только `published`, без черновиков) —
безопасно давать ученикам или коллегам.

Изначально кнопку сделали в панели преподавателя рядом с каждым фильтром курса,
потом перенесли на саму страницу курса — так логичнее (ссылка на страницу лежит
на самой странице, а не в панели). Логика копирования вынесена в общий скрипт
`copyScript`, который теперь используют и страницы курсов, и панель преподавателя
(раньше копирование ссылок на материалы работало только в панели).

## Стандартный цикл работы (напоминание)

```bash
node build.mjs                          # собрать и проверить на ошибки
python3 -m http.server 8080 -d _site    # посмотреть локально в браузере
```

Публикация — как обычно: **GitHub Desktop → Commit to main → Push origin**.
GitHub Actions пересобирает и публикует сайт автоматически, около минуты.
