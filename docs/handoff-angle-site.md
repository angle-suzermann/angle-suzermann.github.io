## Если подключаете новый аккаунт Claude к этому проекту

Ничего вручную прикреплять не нужно — подключите в Cowork ту же папку
(`D:\...\angle-site\angle-site` — и `Courses\` рядом, если продолжите оттуда
импортировать). `CLAUDE.md` подхватывается автоматически в любой сессии с этой
папкой, это системный механизм, а не файл для загрузки. Этот handoff — обычный
файл, сам не подгружается, поэтому в первом сообщении новому аккаунту стоит
явно попросить прочитать `CLAUDE.md` и `docs/handoff-angle-site.md` — тогда
контекст (правила репозитория + текущее состояние сайта) будет полным.
Память самого разговора (конкретные решения по спорным черновикам и т.п.)
не переносится, но всё важное из неё уже выписано в эти два файла.

### ⚠️ Регресс: пропала `noindex` у 4 страниц

`build.mjs` копирует папки материалов в `_site/` как есть (`fs.cpSync`, без
шаблонизации) и **не проверяет и не добавляет** `<meta name="robots">` —
эта строка целиком на совести конкретного файла материала. При сегодняшней
правке (переименование картинок/заголовков, коммит «new skill») у четырёх
файлов эта строка исчезла вместе с остальной чисткой `<head>`:

- `empower-b1/unit 4/personality-classwork/index.html`
- `empower-b1/unit 4/personality-homework/index.html`
- `gateway/gw-b2/unit 8/the-passive-classwork/index.html`
- `gateway/gw-b2/unit 8/the-passive-homework/index.html`

Это расходится с тем, что написано в `README.md` («Сайт закрыт от поисковиков:
noindex на каждой странице плюс `robots.txt`») — сейчас у этих четырёх страниц
noindex нет. Сборка это не ловит, потому что `robots` не входит в список
обязательных `REQUIRED` полей в `build.mjs`. Проверено на самом
`build.mjs` (`fs.cpSync` копирует материал целиком, без правок `<head>`) —
не только предположение по диффу.

Два варианта чинить: точечно вернуть строку `<meta name="robots"
content="noindex, nofollow">` в эти 4 файла, или — надёжнее — научить
`build.mjs` при копии материала проверять/подставлять эту мету
автоматически, чтобы конкретный файл не мог случайно её потерять.
Пока не сделано ни то, ни другое — **это первое, что стоит поправить
в следующей сессии**.

### Подпапки-юниты и автоматические вкладки

Материал курса можно (не обязательно) положить на уровень глубже —
`<course-id>/<группа>/<slug>/`, например `as4/unit 9/water-test/index.html`
или `ege-2027/1.Путешествие/essay-38/index.html`. `build.mjs` находит материалы
на любой глубине сам. Название подпапки — это и есть «группа», из неё
строятся вкладки-фильтры на странице курса и третий уровень вкладок в панели
преподавателя (после `family` → уровень).

### Кнопка «скопировать ссылку на курс»

На каждой странице курса — кнопка **🔗 Скопировать ссылку на эту страницу**,
копирует `https://angle-suzermann.github.io/<course-id>/` в буфер обмена.
Логика вынесена в общий скрипт `copyScript`, используется и страницами курсов,
и панелью преподавателя.

### Кнопка «скачать учебник»

Необязательное поле `textbookUrl` у курса в `site.config.json` (ссылка на папку
Google Диска «по ссылке») — если заполнено, на странице курса появляется жёлтая
кнопка **📘 Скачать учебник**. Пока заполнено для: `as2`, `as3`, `as4`, `as5`,
`oxford-phonics/3`. Это ссылка на учебник целиком, не на вырезку под одно
упражнение — решение по авторским правам за Викторией по каждому курсу отдельно.

## Известные хвосты / на будущее

- **Регресс с `noindex`** (см. выше, «⚠️ Регресс») — 4 файла без
  `<meta name="robots">`, не поймано сборкой. Приоритет — почини первым.
- **Конвенция img-нейминга и заголовков** не задокументирована в скиллах
  сайта (`new-test`, `new-worksheet`, `check-material`, `import-material`) —
  риск, что следующая сессия вернётся к старым описательным именам.
- **Gateway to the World B1**, **Oxford Phonics 1, 2, 4, 5** — курсы созданы
  (папки и записи в конфиге есть), материалов пока нет.
- Группировка по подпапкам — опциональная возможность, применена там, где
  Виктория явно попросила (AS, Expert Advanced, Empower B1+, ЕГЭ 2027, Gateway).
  Oxford Phonics и Placement tests остаются плоскими — это нормально.
- Один материал в Empower B1+ (`polina-relative-clauses-modals`) намеренно
  без группы — индивидуальный урок без привязки к юниту учебника.
- **Отдельный слой проекта, не в этом репозитории**: в подключённой папке
  `ANGLE/` (рядом с `angle-site/`) остаются старые Cowork-скиллы для
  одиночных HTML-файлов — `angle-worksheet-template` (TEST/LESSON/
  INTERACTIVE WORKSHEET режимы), `angle-sticky-badge`, `ege-demo-test-builder`.
  Это более ранний, доузаконенный до сайта подход (единичные файлы, которые
  отправлялись ученику напрямую, без каталога и сборки). Сайт `angle-site` —
  актуальный способ публиковать материалы; старые скиллы полезны как
  референс по компонентам (типы упражнений, вёрстка, TTS-хелперы), но
  результат из них теперь нужно приводить к структуре `<course-id>/<slug>/
  index.html` с `ws:*`-метой (см. `import-material` в `.claude/skills`),
  а не отправлять готовым файлом в обход сайта.

## Стандартный цикл работы (напоминание)

```bash
node build.mjs                          # собрать и проверить на ошибки
python3 -m http.server 8080 -d _site    # посмотреть локально в браузере
```

Публикация — как обычно: **GitHub Desktop → Commit to main → Push origin**.
GitHub Actions пересобирает и публикует сайт автоматически, около минуты.
