# ANGLE — звёзды и коллекция Eggdog

## Правила, подтверждённые 11.11.2026

Система общая для всех существующих групповых Students и индивидуальных Plans, а не только Starters/Movers/Flyers. Одна звезда за ВСЁ обязательное домашнее задание к одной дате после принятия в трекере. Несколько упражнений, частей или карточек на эту дату не дают несколько звёзд. Только ✓ / confirmed; pending, suggested, Done и локальные галочки ученика не являются принятием.

Начало — 11 ноября 2026. ДЗ с более ранними датами наград не дают. Ранее поставленные отметки сохраняются. За каждые пять звёзд сервер случайно выдаёт один из восьми положительных существующих Eggdog без повторов до заполнения коллекции; затем новый круг. Общее число звёзд не уменьшается. Рейтинга детей и штрафа за пропуски нет.

## Откуда берётся подтверждение

- Групповые карточки: назначение Homework_Assignments + все обязательные части confirmed; части N/A исключаются. Проверка сохраняет rewardLesson — старое принятие карточки нельзя перенести на новую дату ради второй звезды.
- Обычные группы: датированные Extras с kind=homework, только свои получатели; Phonics с датой. Состояние Progress должно быть ✓; N/A исключается, soft-deleted Extras не учитываются.
- Индивидуальные планы: Tasks данного Plans.id, kind=homework (пустой kind — старое домашнее задание), все обязательные задачи к дате должны иметь ✓. Classwork/before исключаются. Пересекающиеся наборы дат одного ДЗ объединяются и дают одну звезду, а не звезду за каждую дату заголовка.
- Для награды нужна распознаваемая дата. Поддерживаются ISO, DD.MM.YYYY/DD/MM/YYYY и английские даты, используемые существующим трекером. Непонятную дату агент не угадывает. У недатированного Unit-section нет надёжной даты сдачи — для награды назначить конкретное датированное ДЗ через карточку/Extra. Анонимная A2-страница без идентичности и трекера сама по себе наград не создаёт; имён A2 не добавлять без запроса.

## Хранение и защита

Авторитетный журнал — приватная вкладка Google Sheet `Homework_Rewards`, создаётся при первой реальной награде. Поля id/course/studentId/lesson/awarded/ordinal/sticker/source. Строки не удалять и не редактировать вручную ради исправления оценки. Существующие награды при исправлении оценки не отнимаются.

Детерминированный ID «course | studentId | дата(ы)» и серверный LockService защищают от повторов; источники задания дополнительно защищают от переноса уже награждённого задания на другую дату. Для индивидуальных планов namespace course=plan, studentId=Plans.id, имена не склеиваются. Parent APIs возвращают только награды своей идентичности. Учительский `syncHomeworkRewards` требует прежний token. GET только читает, публичная форма не может начислить звезду.

Начисление запускается после сохранения принятия/изменения статуса в сервере. Автоматическая keyed worksheetSubmission может завершить уже назначенную работу по прежнему контракту; рукописные фото остаются suggested до проверки. Ошибка записи награды не откатывает принятую домашку; кнопка «Обновить награды» в учительском трекере безопасно повторяет синхронизацию. До её нажатия дождаться сохранения очереди.

localStorage хранит только ID уже показанной анимации. Удаление localStorage не меняет звёзды, альбом или оценки. На новом устройстве показывается последняя заслуженная награда; на том же устройстве reload её не повторяет. «Посмотреть награду ещё раз» повторяет только эффект.

## Интерфейс и продолжение разработки

`assets/rewards.js` / `rewards.css` — общий presenter. В групповой панели полоса учеников с числом звёзд; личный альбом внутри карточки ученика и parent-view. Во всех индивидуальных планах — альбом выбранного ученика. Карточка ДЗ показывает награды из собственного receipt. Галерея из восьми PNG `assets/brand/rewards/` — существующие положительные Eggdog, исходный движок результатов и его thresholds не меняются.

Звезда вылетает и останавливается, каждый пятый результат раскрывает стикер. Есть закрытие, Escape и повтор; prefers-reduced-motion отключает движение. Не добавлять бесконечную фоновую анимацию. Не выдавать звёзды из JS по локальному проценту.

Скрипт подключать один раз до tracker/individual/homework-submit (defer). build.mjs добавляет его автоматически для будущих таких страниц. homework-submit обновлён до v6; tracker JS версии берутся из хэша при сборке. Код сервера/токены/родительские ключи не публикуются в репозитории.

## Проверки

Изолированные VM-fixtures: partial/pending/no award, все части/карточки, одинаковая дата, повтор, старые даты, перенос дат, N/A/получатели, планы/группы/parent isolation, 45 звёзд → 9 стикеров, первые 8 без повторов, сохранение общего числа, форматы дат. Полный Apps Script fixture: review → ledger → receipt/parent, setTask → plan reward; прежняя регрессия назначений/частей прошла.

Edge390/1440: звезда/стикер/альбом, изображения, Escape/закрытие/replay, reload без повторов, reduced motion, отсутствие overflow и JS errors; реальные страницы группового и индивидуального трекера на fixture API. Настоящие письма, сдачи, оценки и награды детей в QA не создавались. Первая реальная награда должна появиться от обычной настоящей подтверждённой домашки.
